Methodology and limitations

What this prototype checks—and what it does not
Read before use
  • Image model: fine-tuned MobileNetV2, 128×128 RGB input, trained with MobileNetV2 preprocessing. Score threshold is 0.50.
  • Score meaning: the sigmoid output is an uncalibrated fake-class score, not a calibrated probability.
  • Video: samples up to 12 frames across the clip, detects faces with a bundled Haar cascade, and reports the median of frame mean scores. This aggregation has not been validated, and the model was trained on still face images.
  • Audio: not analyzed. The current model has no audio detector.
  • Source reference: optional text supplied by the user. It is not checked against external sources.
  • File fingerprint: SHA-256 identifies the uploaded bytes; it does not establish origin or authenticity.
  • Not connected: blockchain records, watermark detection, community review, and news/context verification.
  • Research data: the reported test split contains 307 images. The project has not established generalization to unseen datasets.
